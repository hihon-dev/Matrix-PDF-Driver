# Matrix PDF-Driver

[English](README.md)

인쇄하면 PDF를 만들어 주는 Windows 가상 프린터입니다.
인쇄할 때마다 저장 위치를 물을 수도 있고, 정해 둔 폴더에 묻지 않고 저장할 수도 있습니다.

- 제작: 주식회사 히온 (Hihon Inc.)
- 화면 언어: 영어(기본), 한국어. 아래 설명의 메뉴 이름은 한국어 화면 기준입니다.
- 지원: Windows 7 SP1 ~ Windows 11 (32비트, 64비트)
- 라이선스: GNU AGPL v3 (`LICENSE.txt`). 함께 들어 있는 다른 프로그램은 `THIRD-PARTY.txt` 참고

## 주요 기능

- **어느 프로그램에서나 PDF로 인쇄**: "Matrix PDF-Driver"라는 프린터가 생기고, 여기로 인쇄한 것이 PDF가 됩니다.
- **두 가지 저장 방식**: 인쇄할 때마다 저장 위치를 묻거나, 정해 둔 폴더에 묻지 않고 바로 저장합니다.
- **규칙으로 만드는 파일 이름**: 고정된 앞 이름에 문서 이름, 날짜, 시각, 인쇄한 사람, PC 이름, 일련번호를 조합합니다.
- **폴더 자동 생성**: 저장 폴더에 날짜나 사람을 넣으면 인쇄할 때 하위 폴더가 만들어집니다.
- **보관용 형식**: 일반 PDF와 장기 보관용 PDF/A-1b, PDF/A-2b, PDF/A-3b를 고를 수 있습니다.
- **품질 선택**: 그림을 원본 그대로 두거나 파일 크기를 줄이고, 컬러·흑백과 페이지 자동 회전을 고릅니다.
- **인쇄 후 동작**: 변환 과정을 잠깐 보여 주고, 만든 PDF를 바로 열고, 실제 프린터로도 동시에 출력할 수 있습니다.
- **글자가 살아 있는 PDF**: 한글을 포함해 글자가 글자로 남아 선택, 검색, 추출이 됩니다.
- **영어와 한국어**: 설정에서 언어를 바꾸고, 설치도 두 언어로 할 수 있습니다.
- **광고·계정 없음, 무료**: GNU AGPL v3 공개 소스입니다.

## 설치

내려받은 `Matrix-PDF-Driver-Setup.exe`를 실행합니다.

1. 관리자 권한을 묻는 창에서 "예"를 누릅니다.
2. 설치 창은 영어로 시작합니다. 첫 화면의 Language에서 한국어를 고르면 한국어로 바뀝니다. 라이선스에 동의하고, 설치 폴더를 확인한 뒤 **설치**를 누릅니다.
3. 설치가 끝나면 프린터 목록에 **Matrix PDF-Driver**가 생깁니다. "지금 설정 열기"를 켜 두면 설정 창이 이어서 뜹니다.

저장 방식, 저장 폴더, 파일 이름은 설치 뒤 설정에서 정합니다. 처음 설치하면 "매번 묻기"로 시작합니다.

여러 PC에 화면 없이 설치하려면 다음과 같이 실행합니다.
`--mode`는 `auto`(자동 저장) 또는 `ask`(매번 묻기)이고 생략하면 `auto`입니다. `--pattern`으로 파일 이름 규칙, `--dir`로 설치 폴더, `--language en|ko`로 화면 언어도 줄 수 있습니다. 인자를 하나도 주지 않으면 설치 창이 뜹니다.

```
Matrix-PDF-Driver-Setup.exe /Q /C:"cmd.exe /d /c .\setup.cmd --mode auto --output C:\MatrixPDF"
```

## 사용

아무 프로그램에서나 프린터를 **Matrix PDF-Driver**로 골라 인쇄합니다.

- **매번 묻기**: 1~2초 뒤 저장 창이 저장 폴더에서 열립니다(서브 폴더 규칙이 있으면 그 폴더). 파일 이름은 규칙대로 미리 채워져 있습니다. 취소하면 버릴지 다시 묻습니다.
- **자동 저장**: 1~2초 뒤 저장 폴더에 PDF가 생깁니다.

PC를 다시 켜도 자동으로 동작합니다.

## 설정

시작 메뉴의 **Matrix PDF-Driver Setting**을 엽니다. 저장하면 다음 인쇄부터 바로 적용됩니다.

| 메뉴 | 항목 | 설명 |
|---|---|---|
| 저장 | 저장 방식 | 매번 묻기 / 자동 저장 |
| 저장 | 저장 폴더 | 이 PC 안의 폴더만 쓸 수 있습니다. "서브 폴더 생성"에서 고른 항목이 폴더 뒤에 그대로 이어 붙고(예: `C:\MatrixPDF\{date}`), 그 이름의 폴더가 인쇄할 때 자동으로 만들어집니다. 한 단계 더 나누려면 사이에 `\`를 직접 넣습니다. |
| 파일 이름 | 앞 이름 | 항상 같은 앞부분. 기본값 `Cube_` |
| 파일 이름 | 추가 이름 | 앞 이름 뒤에 붙는 부분. "추가 이름 생성"에서 고르면 들어갑니다. 기본값 `{datetime}` |
| 파일 이름 | 전체 | 저장 폴더·앞 이름·추가 이름을 한 줄로 보여 줍니다(예: `C:\MatrixPDF\Cube_{datetime}.pdf`). 여기서 고쳐도 위 칸들에 그대로 반영됩니다. |
| 품질 | 형식 | PDF / PDF/A-1b / PDF/A-2b (권장) / PDF/A-3b. 장기 보관에는 2b를 권합니다. 3b는 파일 첨부를 허용하는 형식인데 이 프로그램은 첨부를 넣지 않으므로 내용은 2b와 같습니다. PDF/A는 나중에 어떤 환경에서 열어도 똑같이 보이도록 글꼴과 색 정보를 모두 담는 장기 보관용 형식입니다. 규격 검증 도구(veraPDF)로 판정받은 것은 아닙니다. |
| 품질 | 그림 품질 | "원본 그대로"는 그림을 손대지 않습니다. "파일 크기 줄이기"는 그림을 300dpi로 낮추고 압축합니다. |
| 품질 | 페이지 방향 | 인쇄한 그대로 / 글자 방향에 맞춰 자동으로 돌리기. 세로·가로 용지 방향 자체는 인쇄하는 프로그램의 인쇄 창에서 고릅니다. |
| 품질 | 색상 | 인쇄한 그대로(컬러) / 흑백 |
| 출력 | 변환 과정 보여주기 | 화면 가운데에 진행 바가 있는 작은 창이 잠깐 떴다 사라집니다. "생성 후 PDF 열기"가 꺼져 있으면 끝에 "저장했습니다"가 잠깐 보입니다. |
| 출력 | 생성 후 PDF 열기 | 저장한 PDF를 바로 엽니다. |
| 출력 | 동시 출력 | PDF를 만들면서 고른 프린터로도 인쇄합니다. |
| 정보 (About) | 언어 | English / 한국어. 기본은 영어입니다. 바꾸고 저장하면 창이 그 언어로 다시 열리고, 저장 창과 진행 표시도 같은 언어를 따릅니다. |
| 정보 (About) | | 버전, 제작자, 저장 폴더 열기, 실패한 인쇄물 보기 |

창 아래에는 지금 설정대로면 다음 인쇄물이 어디에 어떤 이름으로 저장되는지 항상 보여 줍니다.

"출력"의 세 가지는 로그인한 사용자 쪽 도우미가 수행합니다. 아무도 로그인하지 않은 동안 만들어진 PDF에는 적용되지 않습니다.
Matrix Ai-Cube로 자동 수집하는 PC에서는 페이지 방향을 "인쇄한 그대로"로 두세요. 자동으로 돌리면 글자 위치가 달라져 템플릿과 맞지 않을 수 있습니다.
넣을 수 있는 항목:

| 항목 | 내용 | 예 |
|---|---|---|
| `{title}` | 인쇄한 문서 이름 | 시험성적서 |
| `{datetime}` | 날짜와 시각 | 20261008_150405 |
| `{date}` `{time}` | 날짜, 시각 | 20261008, 150405 |
| `{year}` `{month}` `{day}` | 연도, 월, 일 | 2026, 10, 08 |
| `{user}` | 인쇄한 사람 | hong |
| `{computer}` | PC 이름 | LAB-PC01 |
| `{printer}` | 프린터 이름 | Matrix PDF-Driver |
| `{counter}` | 일련번호. `{counter:04d}`처럼 쓰면 자릿수를 맞춥니다 | 12, 0012 |

같은 이름의 파일이 이미 있으면 뒤에 `_2`, `_3`이 붙습니다.

## 제거

제어판의 프로그램 제거에서 **Matrix PDF-Driver**를 지웁니다.
저장된 PDF와 설정은 지워지지 않습니다. 설치 폴더에서는 이 프로그램이 넣은 파일만 지웁니다.

## 알아 둘 점

- **PDF 안의 글자를 읽어야 하는 경우** (예: Matrix Ai-Cube로 결과를 자동 수집)
  프로그램에 따라 글자 정보 없이 인쇄하는 것이 있습니다. 이런 PDF는 눈으로는 정상이지만
  글자를 뽑아낼 수 없습니다. Windows 11의 새 메모장이 그 예입니다.
  대상 프로그램에서 한 번 인쇄해 보고, PDF를 열어 글자가 마우스로 선택·복사되는지 확인하세요.
- **Matrix Ai-Cube와 함께 쓸 때**
  저장 폴더를 폴더 Watcher의 `Incoming` 폴더로 지정하면 인쇄물이 자동으로 올라갑니다.
  템플릿은 이 프린터로 만든 PDF로 훈련해야 합니다. 프로그램 자체의 PDF 내보내기로 만든 파일과는
  글자 위치가 다를 수 있습니다.
- 인쇄 중에 PC가 꺼지거나 프로그램이 멈춰 있어도 인쇄물은 Windows 인쇄 대기열에 남았다가
  다시 동작하면 처리됩니다.

## 문제 해결

| 증상 | 확인할 것 |
|---|---|
| PDF가 생기지 않음 | 설정 창 오른쪽 위가 "동작 중"인지 확인. "멈춰 있음"이면 PC를 다시 켜거나 설치 파일을 다시 실행 |
| 저장 창이 뜨지 않음 | 로그아웃했다가 다시 로그인. 관리자 계정으로 직접 화면 없이 설치한 경우 도우미는 다음 로그인부터 뜹니다 |
| 인쇄했는데 폴더가 비어 있음 | 설정 창 정보 탭의 "실패한 인쇄물"을 열어 `.reason.txt` 파일의 내용 확인 |
| 자세한 기록 | `C:\ProgramData\Matrix PDF-Driver\logs\driver.log` |

## 동작 방식

```
프로그램에서 인쇄
  → 프린터 "Matrix PDF-Driver" (Windows 기본 PostScript 드라이버 "MS Publisher Color Printer")
  → 포트 127.0.0.1:9100 (이 PC 안에서만 열림. 9100이 사용 중이면 9101~9119 중 빈 번호)
  → MatrixPdfDriver.exe --run (PC를 켤 때 SYSTEM 계정으로 자동 실행)
  → Ghostscript로 PDF 변환
  → 묻지 않고 저장: 저장 폴더에 .tmp로 쓴 뒤 .pdf로 이름 변경
  → 매번 묻기: 대기 폴더에 두면 MatrixPdfDriver.exe --agent 가 저장 창을 띄움
```

수신 프로그램은 화면이 없는 SYSTEM 계정으로 돌기 때문에 저장 창을 직접 띄울 수 없습니다.
그래서 로그인한 사용자마다 도우미(`--agent`)가 하나씩 함께 뜨고, 저장 창은 도우미가 그 사용자 권한으로 띄웁니다.
여러 사람이 동시에 로그인한 PC에서는 인쇄한 사람에게 먼저 창이 뜨고, 30초 안에 받지 않으면 다른 사람에게도 뜹니다.

| 위치 | 내용 |
|---|---|
| `C:\Program Files\Matrix PDF-Driver\` | 실행 파일, Ghostscript(`gs\`), 라이선스 |
| `C:\ProgramData\Matrix PDF-Driver\config.json` | 설정 |
| `C:\ProgramData\Matrix PDF-Driver\logs\` | 기록 (5MB × 5개) |
| `C:\ProgramData\Matrix PDF-Driver\failed\` | 변환하지 못한 인쇄 데이터와 이유 |
| `C:\ProgramData\Matrix PDF-Driver\pending\` | 저장 위치를 묻기 전 잠시 두는 PDF |

## 빌드

준비물:

- Python 3.8 32비트 (Windows 7을 지원하는 마지막 버전. `winget install Python.Python.3.8 --architecture x86 --scope user`)
- `vendor\ghostscript\`에 Ghostscript 32비트 공식 배포판의 `gswin32c.exe`, `gsdll32.dll`, `vcredist_x86.exe`
  (공식 설치 파일 `gs10080w32.exe`를 7-Zip으로 풀면 나옵니다)

```powershell
& "$env:LOCALAPPDATA\Programs\Python\Python38-32\python.exe" -m pip install -r requirements-build.txt
& "$env:LOCALAPPDATA\Programs\Python\Python38-32\python.exe" -m unittest test_matrix_pdf_driver
.\build.ps1
```

결과물은 `dist\Matrix-PDF-Driver-Setup.exe`입니다.
코드 서명 인증서가 있으면 `-SigningCertificateThumbprint`로 지문을 넘깁니다.
`-PublishDirectory <폴더>`를 주면 설치 파일을 그 폴더에도 복사합니다(예: 내려받기를 제공하는 웹 서버의 폴더).
서명하지 않은 설치 파일은 Windows가 실행 전에 경고를 띄웁니다.
